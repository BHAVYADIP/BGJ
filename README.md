# BGJ — Cyber Chaukidaar

A privacy-first breach monitoring application built from the Cyber Chaukidaar concept.

## Scope
- Email exposure checks through a legitimate breach-intelligence provider
- Password exposure checking using k-anonymity
- Domain monitoring architecture
- Server-side provider adapters
- No local copy of breached datasets
- No storage or display of passwords, tokens, or raw leaked records

## Status
Initial foundation. Provider credentials are intentionally not committed.

## Environment
Copy `.env.example` to `.env` and provide secrets through your deployment platform.
